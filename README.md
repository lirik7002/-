# Эмулятор оболочки ОС (Вариант 2)

## 1. Общее описание
Эмулятор командной строки UNIX-подобной ОС с GUI на tkinter.
Работает с виртуальной файловой системой (VFS) из XML-файла,
все изменения — только в памяти.

## 2. Функции и настройки
### Команды
- ls [path] — список содержимого каталога
- cd <path> — переход в каталог
- tail <file> [n] — последние n строк файла (по умолчанию 10)
- tree [path] — рекурсивное дерево
- mkdir <path> — создать каталог
- touch <path> — создать пустой файл
- exit — выход

### Параметры командной строки
- --vfs <path> — путь к XML-файлу VFS
- --script <path> — путь к стартовому скрипту
- --debug — отладочный вывод параметров
