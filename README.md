# dep-visualizer

Инструмент визуализации графа зависимостей pip-пакетов.

## Возможности
- Сбор прямых зависимостей через PyPI JSON API.
- BFS-обход графа без рекурсии с обработкой циклов.
- Фильтрация пакетов по подстроке.
- Тестовый режим с файлом описания графа.
- Топологический порядок загрузки.
- Экспорт в D2 и PNG.

## Установка
```bash
pip install pytest  # только для запуска тестов
# Установка d2 (для рендера PNG) - инструкция на https://d2lang.com/
